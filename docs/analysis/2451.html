【催化劑與風險】

催化劑

  • 記憶體報價續漲：這是唯一真正的引擎，ASP 上漲直接灌毛利率。
  • 工控產品占比提升：高毛利結構性改善，比報價週期更持久，是這檔最有價值的部分。

風險

  • 週期見頂風險（最大）：PER 4.95 倍 + EPS 一年成長 28 倍 + 法人公開示警「記憶體狂歡恐進入倒數」。三個訊號指向同一件事。

  • 形態風險：26.8% 的樞紐寬度，任何一根長黑就能吃掉數週漲幅，且沒有合理的停損位置可守。
  • 族群不同步：兩檔龍頭財報創高卻帶不動族群，通常代表資金已經在撤離這個題材。

【一句話判斷】

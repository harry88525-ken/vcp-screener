催化劑與風險

催化劑

  • 法人 EPS 翻倍上修：2026 年 EPS 預估 9.91 元，若後續季報持續超預期，評價有重估空間。
  • DRAM 缺貨延續至 2027：公司法說會親口說的，是最強的多頭論述。
  • DDR4 合約價季增 90%+：報價循環仍在上升段。
  • 2027 產能已被預約完畢：能見度極高，這在半導體業很少見。
  • 千億營收里程碑：若全年營收站上千億，會是明確的媒體與法人焦點事件。
  • 9/07 法人單日大買 4,998 萬：可能是籌碼轉折的第一根訊號。

風險

  • 距 52 週高 -22.91%：上方套牢賣壓厚重，這是本檔最致命的技術缺陷。突破 192 後可能立刻遇到解套賣壓。
  • 投信連續買超 0 天：四檔最弱，機構完全沒有在建倉。
  • 循環股獲利高點：PER 19.85 是建立在史上最好的季度上，報價一反轉評價會雙殺。
  • RS 線未創高：相對強度品質不如帳面 RS 98 好看。
  • 族群跑輸大盤：rs_vs_mkt 三期全負，大盤走弱時這種結構最脆弱。
  • 股利政策不穩：配息紀錄斷續，對長線資金吸引力不足。
  • 產品線相對分散：NOR Flash／NAND／利基 DRAM 混合，單一報價的獲利彈性不如純 DRAM 廠，上升循環中彈性較小，下降循環中也未必更抗跌。

一句話判斷

離扣扳機只剩 6.7%，是本批最快會有答案的一檔，但 -22.91% 的距高點差距讓這個突破先天矮一截——掛警示可以，重倉不行。

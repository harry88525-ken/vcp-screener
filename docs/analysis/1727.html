獲利同步放大：2026Q2 營收 6.38 億（YoY +23%）、毛利 1.13 億、毛利率 17.8%（2025Q2 僅 12.3%）、營業利益 6031 萬（2025Q2 僅 784 萬）、EPS 0.38 元。Q1 EPS 0.28。對比 2025 全年四季 EPS 只有 -0.05 / 0.06 / 0.02 / 0.01，這是從幾乎不賺錢直接跳到有規模獲利。

估值是硬傷：PER 131.9 倍、PBR 5.39 倍、殖利率 0.16%（114 年只配 0.15 元，還比 113 年的 0.5 元縮水）。近四季 EPS 加總 0.69 元，就算給未來四季 EPS 樂觀估到 1.6 元，PER 也還有 57 倍。市場已經把「半導體轉型成功」預先計價進去了。

現金流是明顯減分項：2026Q2 單季營運現金流只有 487 萬元，同期稅後淨利 4881 萬——現金流只有淨利的 10%。上半年累計營運現金流 4796 萬，也遠低於累計淨利 8471 萬。營收衝高的同時應收帳款與存貨在吃現金，這是擴產期常見、但必須盯住的品質瑕疵。

催化劑與風險

催化劑：（1）第五條電子級硫酸產線滿載貢獻，Q3、Q4 營收有機會續創高；（2）打進更先進製程的晶圓清洗供應鏈、客戶認證進度；（3）9 月營收若續破 2.5 億，年增率可望維持 50% 以上；（4）Q3 財報 EPS 若站上 0.45 元，全年 EPS 破 1.4 元的預期會被市場追認。

風險：（1）PER 132 倍、PBR 5.4 倍，估值容錯空間極低，成長率一旦低於預期，殺估值的幅度會遠大於獲利下修幅度；（2）營運現金流只有淨利的 10%，若應收與存貨續增，擴產的資本支出可能得靠舉債或增資；（3）電子級化學品是客戶高度集中的生意，單一大客戶砍單即重傷；（4）族群排名第 13、無族群共振；（5）法人零認養，突破後上攻缺乏籌碼推力。

一句話判斷

基本面轉型是真的、營收年增 62% 也是真的，但股價離樞紐還有 16.5%、估值已到 132 倍 PER、法人一張都沒在追——這是「故事很好、位置很爛」的典型，先掛追蹤等它重新收緊，不要現在追。

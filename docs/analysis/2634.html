【結論先行】

漢翔(2634) 目前判定為 尚未突破／觀察，且是本批條件最鬆散的一檔。

  • 還差 8.8%：as-of 2026-08-27 收盤 70.3 元，樞紐高 76.5 元，是本批第二遠的距離（僅次於創見(2451) 的 10.6%）。

  • 缺的條件：需要價格收斂、放量突破 76.5 元，且法人停止劇烈拉扯。目前籌碼是本批最混亂的——單日動輒 ±1,500~3,000 萬股來回，8/28 單日大賣 -2,751 萬股。
  • 信心等級：低。基本面轉機成立，但族群排名第 12（非前段班）、型態最寬、籌碼最亂，三項扣分。

【催化劑與風險】

催化劑

  • 營運現金流 +75.66 億：是同期淨利的 7.8 倍，強烈暗示手上有大額專案預收款，未來數季的營收認列有底。
  • 毛利率跳升到 19.0%：若 Q3 能守在 15% 以上，代表產品組合真的往高毛利業務轉移，估值框架會改變。
  • 距 52 週高點僅 -8.1%：本批最接近前高，一旦帶量突破，上方套牢賣壓最輕。
  • 國防預算與航太自主題材：屬結構性長線順風，不受消費電子循環影響。

風險

  • 籌碼最混亂：法人單日 ±1,500~3,000 萬股來回、8/28 單日大賣 2,751 萬股，在股價貼近前高時出現這種背離是明確警訊。
  • 樞紐帶寬 17.39% 過寬：型態尚未收斂，假突破成本高，這是六檔裡技術結構最差的。
  • 毛利率跳升可能是一次性：從 7.8% 到 19.0% 的跳躍，在專案型製造業通常來自單一高毛利交機的認列，Q3 有很大機率回落。
  • EPS 波動劇烈：-0.24 → 0.21 → 0.56 → 0.28 → 1.02，沒有穩定趨勢，任何以 Q2 外推的估值都不可靠。
  • 族群分類失真且不強：被歸在航運業（排名第 12、6 個月相對大盤 -34.37%），既拿不到族群加分，分類本身對航太國防業務也沒有解釋力。
  • 配息連年腰斬：1.42 → 1.38 → 0.778 元，殖利率僅 1.15%，無防禦性。

【一句話判斷】

漢翔(2634) 的 2026Q2 財報（毛利率翻倍、現金流 +75.66 億）確實漂亮，但型態最寬、籌碼最亂、族群最弱、風報比最差——這是本批最該放進觀察清單而非交易清單的一檔，等它先把價格壓縮乾淨再說。

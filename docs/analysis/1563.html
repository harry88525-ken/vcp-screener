風險

  • 最大風險是系統性的，不是公司的：L1 沒有公司行動濾網，把 25% 現金減資造成的價格跳空讀成強勢型態。任何根據 L1 的 pivot 80.5 / stop 72.9 下單的決策，都建立在錯誤的圖上。
  • 匯率主導 EPS：Q2 營益 1.946 億元卻只剩稅後 0.713 億元，日圓匯損吃掉大半。台幣 9/21 收 31.758 元、連 3 升，對出口商是持續性逆風；Q3 回沖是一次性。
  • 存貨與資本支出雙重壓力：存貨 59.46 億元（約 362 天），PP&E 85.49 億元且年增 12.2%，屏東廠、嘉義廠都還在燒錢，同時又減資發出 5.64 億元現金。

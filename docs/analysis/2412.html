【結論先行】

觀察（信心：中）。是真的強，但「強」的本質是避險資金的防禦性買盤，不是成長股爆發。三大法人近三日合計買超約 2.19 萬張、在大盤 11/19 重挫 1,768 點當天逆勢創歷史新高——這是資金躲進來，不是搶進來。基本面穩健但 Q3 超標含一次性資產活化收益；PER 30 倍貼近一年高（32.1）、殖利率壓到 3.16%。可等站穩 171 樞紐、且量能確認後小倉位參與；目標要比 VCP 機械值保守，電信股不會 +20%。

勝方：空方小勝。多方的籌碼與相對強度是真的，但空方抓到兩個要害——獲利超標含一次性、估值已在一年高檔。結論不是「跳過」，而是「這不是 VCP 主攻股的料，只能當防禦性小倉位」。

【族群定位】

  • L2 歸在「電子工業」（197 檔、第 23 名、真族群），但這是分類問題——中華電實為電信業。同業 台灣大(3045)、遠傳(4904) 都是防禦型，中華電是市占（行動營收市占 41%）與獲利的龍頭。
  • 在電子工業族群內前段班是 冠西電(2466)、東訊(2321)、華經(2468)、鼎元(2426)、聯發科(2454)——它不是那條主線的馬；它是電信這條防禦線最強的馬。
  • 族群 1/3/6 月動能 -29% / -23% / -26%，對照中華電逆勢新高，正說明資金是「從電子撤到電信」。

【基本面＋估值】

  • 營收：2026 年月營收穩定在 190–244 億，8–10 月明顯墊高（233 / 244 / 237 億）。
  • 獲利：季 EPS 1.30 → 1.38 → 1.57，前三季 EPS 4.25；Q3 毛利 258.8 億、營業利益 153.8 億皆創高，但含一次性收益。
  • 現金流：營運現金流 YTD 600.6 億，Q3 單季 234 億，品質好。
  • 股利：114 年配 5.2 元；以 164.5 計殖利率約 3.16%。
  • 估值：PER 30.2（一年區間 26.2–32.1）、PBR 3.37——已在區間上緣。

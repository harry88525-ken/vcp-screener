第二回合：賠率的真實數學

  • 以 8/27 收盤：台灣大(3045) = 115.5 元 → 對價現值 = 92.5 + 0.84 × 115.5 = 189.5 元

  • 破局情境：股價回宣布前約 142.5 元 → -21.9%

結論先行

尚未突破／觀察。欣銓(3264) 目前收 233.5，樞紐高 239.5，距離突破點還差約 2.6%，屬於 READY tier1（即將收緊、尚未突破）。基本面是這五檔裡最漂亮的一檔——2026Q2 EPS 2.44 元、年增 105%，毛利率從 36.3% 拉到 40.2%，7 月營收年增 52.3% 還在加速。但技術面有三個沒到位的地方：

信心等級：中。基本面加速度給高分，但 R:R 僅 1.28、風險 15.66% 偏寬，族群短期動能又在落後，屬於「值得盯、但要用小倉位試」的等級。

族群定位

  • 所屬族群：半導體業，118 檔成員，族群排名第 2（real_group = true，是真族群不是拼湊的）。
  • 族群動能：126 日 +26.4%（強），但 63 日 -11.2%、21 日僅 +5.3%——長多、短弱。更關鍵的是相對大盤（rs_vs_mkt）21/63/126 日全部是負的（-1.4% / -11.8% / -10.0%），代表這條主線近半年其實在「跑輸大盤」，靠的是前期累積的漲幅撐排名。

  • 季 EPS：2026Q2 為 2.44 元，年增 105%（2025Q2 為 1.19 元）；連續四季 1.75 → 1.79 → 1.95 → 2.44，逐季墊高。近四季 TTM EPS 約 7.93 元。
  • 毛利率：2026Q2 為 40.2%，2025Q2 為 36.3%，2024Q4 谷底 27.5%——七個季度從 27.5% 拉到 40.2%，這是測試代工產能利用率回升＋高階測試佔比提升的典型軌跡，也是最有說服力的基本面證據。
  • 營益率：2026Q2 為 30.4%（2025Q2 為 26.4%），淨利率 25.5%（去年同期 16.5%）——營收增速 32% 而淨利增速 105%，明顯的營運槓桿。

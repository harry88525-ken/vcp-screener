【基本面 + 估值】

  • 獲利剛從虧損翻身：季 EPS 0.94 → 0.54 → 0.43 → 0.40 → 0.14 → -0.31 → 0.64 → 0.74（26Q2）。2025Q4 才剛虧損，2026 連兩季回升。
  • 毛利率是真的在改善：31.6% → 31.1% → 26.8% → 22.8%（谷底）→ 32.3% → 35.0%；營益率從 -5.8% 翻到 +8.2%。連兩季改善且毛利率創新高，這是硬證據。
  • 但營收沒有明顯放大：季營收 7.17 → 7.60 → 6.94 → 6.82 → 7.13 → 7.63 億。2026Q2 的 7.63 億只比一年前的 7.60 億高一點點。獲利改善幾乎全部來自 margin，不是來自量。 這一點與正隆(1904) 的問題相同——margin 驅動的復甦續航力有限。
  • 7 月營收是唯一的量能訊號：3.18 億，月增 28.98%、年增 43.79%，是近 13 個月最高。這是好消息，但只有一個月，需要 8 月營收確認。

  • 本業定位（富果法說會備忘錄 2025/12/16）：聚鼎核心產品為 PPTC（高分子正溫度係數熱敏電阻）電路保護元件，應用於消費電子、車用、工業電源；並透過併購跨入散熱基板，切入高階散熱應用市場。

【催化劑與風險】

  • 真催化劑一：TCLAD 散熱基板隨美國國防軍工訂單回流復甦。 這是 2025 年虧損的主因，反轉就是最大彈性來源。

  • 風險一：累計年增僅 5.68%，復甦基礎不厚，單月數字不能外推。
  • 風險二：獲利改善靠 margin 不靠量，季營收兩年幾乎沒成長。

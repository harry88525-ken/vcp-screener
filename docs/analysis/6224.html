【結論先行】

不追。信心等級：中。

聚鼎(6224)今天被 L1 判定為 BREAKOUT，但這是一個「基本面對、技術結構不對」的突破，理由三條：

  • 停損太遠：樞紐高 85.0 元、停損 66.4 元，單筆風險 21.88%。這不是 VCP 該有的收縮口徑（理想 5–8%，可容忍到 10%），代表這個底部根本沒有壓縮完成，是一個寬鬆的長底而非真正的乾燥碟形。
  • 風報比不及格：量測目標 102 元，R:R 僅 0.91。賺的期望值比賠的還小，這種結構就算方向做對，也只是用大風險換小報酬。
  • 突破的不是高點：目前價位距 52 週高點仍有 -12.82%，且 RS 線未創新高。真正的 BREAKOUT 應該是往無壓區走，這檔上方還有整整一段套牢區要啃。

基本面（營收爆發＋毛利修復）和籌碼（法人連續買）都站得住腳，所以不是「這檔不好」，而是「這個點不能用這個停損進」。合理做法是列入觀察，等它拉回打出一個 8% 以內的次級小平台再說。

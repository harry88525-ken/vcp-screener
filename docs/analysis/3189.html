催化劑與風險

催化劑

  • ABF 稼動率爬坡：85% → 年底逼近 95%，每提升一個百分點都是直接落在營業利益上的槓桿。
  • ABF 載板調漲 + 兩年來首度擴產：公司敢擴產代表對需求能見度有把握，這是管理層用資本支出投下的信任票。
  • 輝達 Vera CPU 規格升級與市占提高：高階 ABF 載板層數與面積增加，單價與毛利同步往上。
  • 光模組帶動 BT 載板需求回溫：ABF 之外的第二成長引擎，加上記憶體需求回升。
  • 法人目標價看千元：若股價站上 878 並穿越 959.9 的 52 週高，目標價共識會快速上修。

風險

  • 估值是五檔之最：PER 153.43 倍、殖利率 0.18%。任何一季獲利不如預期，這種倍數的修正幅度會非常暴力。
  • T-Glass 玻纖布缺料：需求旺但出不了貨，這是供給端的硬限制，不是公司努力就能解決。缺料一旦延長到 Q4，營收成長曲線會被硬生生截斷。
  • 處置股（分盤交易）：量能失真、流動性下降，突破訊號可信度打折，且處置本身常伴隨解除後的獲利了結賣壓。
  • L1 賺賠比只有 0.87：這是技術面最大的警訊。距離 52 週高只剩 13.85%，而停損要付出 10.71%，上檔空間被嚴重壓縮。
  • 買盤單一：投信連買日數為 0，全靠外資。09-17 單日就能倒 332 萬股，外資一轉向就沒有承接方。
  • 族群倉位重疊：南亞科(2408)同屬電子工業族群前段班，若兩檔都進場，等於在同一個族群下雙倍押注。

一句話判斷

型態最緊（停損只要 10.71%）、營收連 5 個月新高、現金流轉換率 148% 全場最佳，但 PER 153 倍加上到 52 週高只剩 0.87 的賺賠比——這是一檔「好公司、壞價格、壞位置」的標的，處置期結束前不動，站上 878 後也只給半倉。

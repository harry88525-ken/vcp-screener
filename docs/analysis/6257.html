完整進場計畫

  • 進場：樞紐高 258.5 元。今日收 250.5 元尚未站上，所以正確做法是「258.5 元以上、且要有量的收盤價」才觸發，不是今天市價追。
  • 停損：系統停損 204.0 元。自 258.5 元進場風險 21.08%；自今收 250.5 元算已是 -18.6%。這個停損實務上太寬，建議自訂停損收到 230 元（樞紐區下緣附近，約 -11%），代價是被洗出場機率上升。

  • L1 真實值：目標是 52 週高 279.5 元，reward_risk＝0.39。也就是照系統停損算，賺賠比只有 0.39——賠率不合格。

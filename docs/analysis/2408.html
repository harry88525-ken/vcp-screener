催化劑

  • 獲利品質最乾淨：Q1 業外只占淨利 6.2%，93.8% 來自本業。要押 DRAM 循環，這是純度最高的載具。
  • 循環反轉完整度高：2025Q2 每股虧 1.32 元 → 2026Q1 每股賺 8.41 元，連四季跳升，毛利率一年改善 82.84 個百分點。

風險

  • 週期股的本質風險（最大的一個）：DRAM 是標準的商品化循環產業。67.89% 的毛利率不是護城河，是報價的函數。報價一旦見頂，毛利率會用同樣的速度往回掉——2025Q1 的毛利率是 -14.95%，那不是遠古歷史，是十二個月前。市場給低本益比正是因為知道這件事，別把低 PER 當成便宜，那是循環高點的警告標誌。
  • 技術位置不佳：L1 賺賠比只有 0.39，距 52 週高僅 9.31% 但停損要付 13.8%。
  • 樞紐剛被測試過：09-15 收盤 465.5 元精準踩在停損價上。六個交易日前才走到破位邊緣的結構，穩定度不如收斂平滑的 VCP。
  • 8 月月增率驟降到 1.88%：7 月還有 49.3%，8 月剩 1.88%。可能是產能天花板，也可能是拉貨動能放緩，9 月數字是關鍵驗證點。
  • 模組廠已出現月減：創見(2451)8 月營收月減 6.88%。模組端通常比顆粒廠更早感受到終端需求變化，這是供應鏈裡第一個轉弱的環節。
  • 買盤單一：近 20 日外資買超 98,213 張、投信只有 2,713 張，trust_streak ＝ 0。外資一轉向沒有第二道承接力量。
  • 與南亞(1303)的重疊風險：南亞(1303)Q2 獲利過半來自南亞科(2408)權益法認列。兩檔同時進場＝同一個 DRAM 循環押兩次。
  • 本次資料缺口：營運現金流、官方 PER 區間、殖利率、股利政策本次無法查證（FinMind 403），Q2 財報數字亦僅由新聞的月營收推估。這份報告的基本面完整度低於其他四檔，做決策時請把這個不確定性計入。
